## 🎓 Educational Simulation Project

### CyberSim: A Game-Based Stimulation of Cyber Threats Operation and Client- Driven Tasks
**[Final Year Project]** 
**Tech Stack:** Unity, C# scripting

**About This Project:**
This project is an educational serious game aimed at providing hands-on experience with cybersecurity concepts in a safe, interactive environment.  

**Key Features & Achievements:**
• Designed interactive gameplay systems and missions to simulate real-world cyber threat scenarios.  
• Implemented core mechanics including malware removal, file inspection, and cryptography within a game environment.  
• Applied principles of game design and user experience (UX) to create an engaging and educational simulation.
