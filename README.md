# 🛡️ CyberSim: Educational Cybersecurity Simulation

## 📌 About This Project
CyberSim is a gamified educational software designed to provide hands-on experience with cybersecurity operations (e.g., malware removal, file inspection, and cryptography).
Unlike traditional technical training, this project was built with a strong focus on User Experience (UX) and User Requirement Analysis to bridge the gap between complex IT concepts and non-technical learners.

## 🛠️ Core Competencies & SDLC Execution
### 1. Business Analysis & Metaphor Design
* The "Restaurant" Metaphor: Translated abstract and intimidating cybersecurity threats into an intuitive virtual "restaurant" ecosystem.
* User-Centric Logic: Designed gameplay loops where analyzing malicious threats is akin to reviewing "recipes," and handling incidents is mapped to "serving customers". This significantly lowered the cognitive load for beginners.

### 2. User Requirement Analysis & Agile Development
* Conducted requirement analysis targeting non-IT students, identifying three core pillars: Simplification of technical jargon, Immediate Feedback loops, and an Intuitive UI.
* Adopted the Agile Methodology (Plan -> Design -> Develop -> Test -> Release -> Feedback) to iteratively build and refine distinct operational modules (Order, Eliminate, Inspect, Defend, Encrypt, Decrypt).

### 3. Quality Assurance & Usability Testing
* Designed and executed functional UI/UX test cases ensuring cross-compatibility and interface stability.
* Validated edge cases such as dynamic resolution scaling (TC01), fullscreen toggling (TC02), and preserving aspect ratios for dynamic image loading (TC03).
* Employed Mixed Methods (Qualitative surveys and Quantitative metrics) to evaluate system usability and continuously refine the difficulty curve.

## Tech Stack
* **Engine:** Unity (C#)
* **Design Tools:** Pixel Studio (UI/UX Assets)
* **Methodology:** Agile SDLC, Mixed Methods Research
